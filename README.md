# Mobile Sales & Customer Analytics Dashboard

## Project Overview

This project is an interactive Mobile Sales and Customer Analytics Dashboard developed using Microsoft Power BI. The dashboard is designed to analyze mobile sales performance across different brands, products, categories, cities, and customer ratings.

It provides sales analysis on a daily, monthly, quarterly, and yearly basis. The dashboard also includes city-wise analysis using map visualization to understand the geographical distribution of sales.

## Key Analysis

* Brand-wise sales analysis
* Category-wise sales analysis
* Phone type and model-wise sales analysis
* City-wise sales analysis
* Daily, monthly, quarterly, and yearly sales trends
* Customer rating analysis
* Geographical sales analysis using map visualization
* Identification of top-performing brands and products

## Dashboard Features

The dashboard includes interactive charts, KPI cards, slicers, filters, and drill-down functionality. Users can filter the data based on different brands, categories, cities, dates, and other business dimensions to analyze sales performance in detail.

## Tools and Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling
* Data Cleaning
* Data Visualization
* Time Intelligence

## Business Objective

The main objective of this project is to analyze mobile sales data and identify important sales patterns across products, brands, cities, and time periods. The dashboard helps provide a clear view of sales performance and supports data-driven business decisions.
